# One material per line:
#   name, mass, type, color, friction, strength, break style, extras...
#
# type:      solid  = never moves (walls, stone)
#            rigid  = everything painted in one stroke becomes one piece
#                     that falls, tumbles and breaks (steel, concrete, rock)
#            powder = falls and piles up (sand, dust)
#            liquid = falls and flows sideways (water, lava)
#            gas    = rises and drifts around (steam, smoke)
#
# mass:      density compared to water (water = 1, steel = 7.8).
#            Heavier things sink through lighter powders, liquids and gases.
#            It's also how strongly it pulls in mutual gravity (0 = no pull),
#            and how hard it hits things.
#
# color:     hex code like #ff8800 (optional, leave empty to get a random color)
#
# friction:  0 to 1 (optional, default 0.3, not used by solid or rigid)
#            0   = slippery, slides around freely (water)
#            0.5 = grips a bit, makes steeper piles (sand)
#            1   = only moves straight toward gravity, holds its shape
#
# strength:  how much it takes to break it (optional, only for solid and rigid)
#            0 = unbreakable (default for solid), rigid default is 5
#            higher = survives bigger hits, longer overhangs and more weight on top
#            roughly the real (pulling-apart) strength in units of 2 MPa
#
# break style: how it breaks when hit hard (optional, only for solid and rigid)
#            brittle = cracks into chunks (rock, concrete, glass) - the default
#            ductile = dents and bends instead (metals)
#            snap    = snaps in two along a crack, with a few splinters (wood)
#
# EXTRAS (optional, any order, after the type):
#   hot=1450:Molten Steel   above 1450 C it turns into Molten Steel
#   cold=1400:Steel         below 1400 C it turns into Steel
#   temp=1200               its temperature when you paint it (default 20 C)
#   heat=0.5                how well it passes heat on, 0 to 1 (default 0.2)
#   bounce=0.8              how bouncy it is, 0 to 0.95 (default 0.15)
#   life=60                 only lasts about this many ticks, then vanishes (fire, smoke)
#   burn=300                catches fire at this temperature, then burns until it
#                           reaches its hot= temperature and turns into that
#   burnrate=6              how fast it burns through (default 6; higher = burns out sooner)
#   explode=1               blows up instead of burning; how strong, per cell
#   shock=3                 also blows up if it hits something at this speed (cells per tick)
#   thrust=60               burning gas pushes on what's around it (rocket fuel)
#   stick=1                 sticks to any piece it's painted against (fuel inside a rocket)
#   latent=60               boils / melts slowly: holds at its hot= temperature, soaking up
#                           heat (and chilling what's around it), about this many heat steps
#   ignite=0.25             chance to set fire to something burnable it touches
#                           (flames always do; burning fuel too, if it has ignite=)
#   neutron=1               it's a neutron: flies straight, goes through most things
#   fission=0.1             chance (per cell a neutron goes through) to split: lots of
#                           heat and 2-3 more neutrons. Enough of it together = chain reaction
#   fusion=0.05             like fission, but it's used up in a flash of heat (deuterium)
#   radio=0.001             chance each tick to give off a neutron by itself
#   absorb=0.3              chance (per cell) to soak up a neutron going through it
#                           (default 0.3 for solids, 0.03 for everything else)
#   clone=1                 copy block: copies the first loose thing that touches it,
#                           then keeps making more of it
#   grow=0.03               plant: chance per tick to grow into water it touches
#   sprout=1                seed: turns into the plant when it touches water
#   gol=1                   Game of Life cell (Conway's rules, one generation every 4 ticks)
#
# Lines starting with # are ignored.
# After editing, press "Reload particles" in the sim.
